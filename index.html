Designed for reuse

How this connects to S&box

  1. Give each vehicle LED/light module a logical channel name.
  2. Map those channel names to the actual light objects on the vehicle.
  3. Load this JSON in an S&box C# sequencer that drives emissive visuals and nearby light components.
  4. Keep the same pattern for other vehicles by remapping their channels.
